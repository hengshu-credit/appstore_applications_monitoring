# 主题卡片与页面布局验收

日期：2026-11-06。以下按本轮最终要求记录，替代此前卡片底边色条和固定可见页脚的布局。

- 国家卡片显示本地国旗、国家/地区名称、APP总数和四项状态数字。10px矩形占比条位于总数与状态数字之间；颜色来自主题主色、渐变辅色及背景色，数字使用正文色。导入参考不计入实测比例。
- 大数字使用“万/亿”等紧凑格式，单元格限定宽度并截断溢出。鼠标悬停或键盘聚焦显示完整数量和占比，Escape关闭；切换页面、筛选或分组时清理浮层。浮层用顶层弹出机制避免被滚动容器裁切。
- 左侧分组外框铺满左列，与右侧看板等高；内部列表保持吸附，窄屏恢复横向分组选择。
- Header移除右上角范围文字，按内容收紧高度。工作区说明放到页签下方；采集页合并重复说明，并把新建按钮放在同一行。Logo下方留白减小。
- Footer采用文档末尾布局：长页面滚动到底才显示，短页面仍贴合视口底部，保留原说明、版权及链接。

## 实际验证

- Chrome 1920px：色条实际高度10px，位于总数下方、四项状态上方；可见国旗加载正常；国家卡片无横向溢出。左右分组区域实测同高2536.28px。
- Header实测约50–51px；采集页页签底边114.4px、说明顶边135.5px，新建按钮与说明同区，重复说明已去除。
- 390px：页面宽381px，状态数字未越界；浮层宽280px并保持在视口内。键盘聚焦、Escape和鼠标悬停通过。
- 长页面页脚初始位于视口之外，滚动到底后底边与视口底部相差小于1px；短页面页脚直接贴底。
- 浅色紫粉渐变、深色蓝色均检查过；预设及自定义纯色/渐变的两种明暗模式有自动化覆盖。浏览器恢复测试前的主题配置和默认视口。
- 前端全套68项测试、语法检查及生产构建通过；末次浮层滚动调整后，9项分组测试再次通过。Docker前端已构建并更新。未修改后端数据或采集设置。
