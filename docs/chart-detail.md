# 榜单两行排版与详情入口

2026-11-03更新。

全球榜单的“按国家分组”和“按榜种横向对比”共用固定排版：应用行高64px，名称最多两行（20px行高、40px上限），超过两行显示省略号；完整名称保留在按钮文本及原生title中，悬停可查看。名称不再因长度不断撑高行，图标和相邻榜单行保持对齐。单行名称在两行预留区域中垂直居中。

每个榜单标题和底部“查看完整榜单与应用资料”均可点击，进入独立榜单详情。链接保留商店、国家、请求语言、榜种、分类和用户指定的历史观察时点。详情页支持搜索应用/ID/开发者及25/50/100条分页，保留原始名次，不因筛选重新编号。顶部切换市场时更新详情链接并重置分页；返回全球排行榜保留原筛选布局。

详情表显示名称、开发者、分类、售价、评分、评分数、Google公开累计安装数、版本、更新时间与资料观察时间。点击应用名称继续进入该市场的应用详情。当前公开源未提供、或尚未采集的字段显示为空，不补造下载量和评分。

应用资料按商店/国家/语言读取。历史榜单只关联不晚于该榜单快照的详情版本；普通查询使用当前市场最近成功资料并单列其时间。Apple榜单原始响应中已有的价格、币种、分类、发布日期可作为缺失字段的补充，无需额外商店请求；原始文件不可读时提示原因，仍保留已保存的排名。详情展示范围是已采集快照的实际返回范围，不声称无限官方排名。

验证：真实中国区三类榜单共30行全部测得64px，名称高度不超过40px；横向对比中5个超长名称触发截断，所有名称的title与完整文本一致。390px视口下页面宽381px，没有页面级横向溢出。实际点击中国付费榜显示100个应用，可翻至第51–100名；售价与分类从保留的Apple榜单响应读取。新增导航测试覆盖市场、分类、历史时点和分页保持，后端测试覆盖资料市场隔离、历史时间限制及榜单字段补充。
