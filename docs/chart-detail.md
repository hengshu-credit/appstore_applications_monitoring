# 榜单两行排版与详情入口

2026-11-03更新。

全球榜单支持两种排版：横向排列每行一个榜单、每列一个应用，图标上方对齐、名称置于下方，位置代表名次而不另标数字；纵向排列按国家上下分组，每个国家内每列只展示一个榜单，保留64px应用行与「排名」「应用」两列。两种布局的名称均最多两行（20px行高、40px上限），超过两行显示省略号；完整名称保留在按钮文本及原生title中，悬停可查看。名称不再因长度不断撑高行，图标和相邻榜单行保持对齐。单行名称在两行预留区域中垂直居中。

省略只发生在第二行末尾；榜单详情的开发者、分类、版本等文本列同样最多两行，超长时才在第二行末尾省略，并保留悬停全文。

每个榜单标题和底部“查看完整榜单与应用资料”均可点击，进入独立榜单详情。链接保留商店、国家、请求语言、榜种、分类和用户指定的历史观察时点。详情页支持搜索应用/ID/开发者及25/50/100条分页，保留原始名次，不因筛选重新编号。顶部切换市场时更新详情链接并重置分页；返回全球排行榜保留原筛选布局。

详情表显示名称、开发者、分类、售价、评分、评分数、Google公开累计安装数、版本、更新时间与资料观察时间。点击应用名称继续进入该市场的应用详情。当前公开源未提供、或尚未采集的字段显示为空，不补造下载量和评分。

应用资料按商店/国家/语言读取。历史榜单只关联不晚于该榜单快照的详情版本；普通查询使用当前市场最近成功资料并单列其时间。Apple榜单原始响应中已有的价格、币种、分类、发布日期可作为缺失字段的补充，无需额外商店请求；原始文件不可读时提示原因，仍保留已保存的排名。详情展示范围是已采集快照的实际返回范围，不声称无限官方排名。

验证：真实中国区三类榜单共30行全部测得64px，名称高度不超过40px；横向对比中5个超长名称触发截断，所有名称的title与完整文本一致。390px视口下页面宽381px，没有页面级横向溢出。实际点击中国付费榜显示100个应用，可翻至第51–100名；售价与分类从保留的Apple榜单响应读取。新增导航测试覆盖市场、分类、历史时点和分页保持，后端测试覆盖资料市场隔离、历史时间限制及榜单字段补充。

## 2026-11-04 筛选交互与稳定性复盘

- 页面筛选输入、选择器和操作按钮统一为42px，header保持34px；刷新为标题后的无边框图标按钮。
- header商店下拉只有Google Play和App Store两个选项，点击切换勾选，可同时选中，至少保留一个。内部`all`仍表示两者，不再提供独立“全部商店”选项。双商店关键词列表分别匹配各商店的市场语言。
- 全球国家筛选复用header的国旗、洲和亚洲分区弹层，支持全选、清空、区域全选、搜索结果批量选择及确认/取消；不改变header的单国家上下文。榜种改为浮动选项面板，展开不会撑高筛选栏。
- 双商店全球榜按国家和商店分开展示，分页每页6个国家；详情链接保持实际商店，未支持市场明确显示状态。采集预览合并两商店目标，在商店内按基榜去重，跳过未支持市场，保留已有采集配置。
- 修复无效旧筛选导致持续加载失败：恢复时清理未知国家、失效榜种、跨商店分类、异常深度和未来日期；提交前校验日期，错误输入不污染刷新状态。
- 修复慢响应覆盖新选择：筛选变化立即使旧采集预览失效；迟到响应不能恢复旧确认按钮，旧页面响应也不能更新当前页面。全球国家选择独立于header，避免无关的header市场阻断整页。

本地验证：44项前端测试通过（含账户集成），3项全球榜单MySQL测试通过，前后端Docker镜像构建通过。新增回归覆盖双商店链接与分页、市场语言、区域多选/取消、缓存修复、日期校验和异步预览失效。

本轮较早的浏览器检查测得正文控件42px、header控件34px，并验证250地区全选和东南亚11地区全选。账户功能合入后的最终实屏复核未完成：Windows浏览器工具无法可靠确认当前URL而停止。上述自动化测试和构建结果不能替代这项最终视觉检查。

仍需数据条件的内容：真实分国家下载量、iOS下载量、收入/MAU估算，以及完整的各市场实时官方热搜。现有累计安装观察差值、候选语料词频、第三方报告指标分别保留来源与口径，不据此生成上述数据。SDK扫描与广告素材尚未接入。报告关键词汇总和既有来源说明见[榜单增长与关键词发现](discovery-and-keywords.md)。
