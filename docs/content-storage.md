# OceanBase 与对象内容存储

数据库只保存完整正文的内容哈希、长度、对象引用和 SQL 筛选字段。正文写入 SeaweedFS 前使用 Zstd 无损压缩；压缩无收益时保留原字节。读取验证长度与 SHA256，拒绝缺失、损坏、未知编码和超限内容。

应用目录、配置和任务表使用行存；关键词排名、榜单观察明细、每日指标、事件、请求和采集日志使用列存。列存并不保证比行存获得固定倍数的压缩收益，必须以实际数据及索引统计为准。

事务顺序是上传不可变对象，再提交数据库引用。不同进程可能重复上传同内容，但对象键一致；事务失败留下的未引用对象暂不自动回收。删除对象需要结合数据库引用、未完成写入和备份保留期设计离线回收，不能仅凭某一时刻没有引用就删除。

对象以数据库名作为前缀，备份/恢复使用相对引用。测试数据库使用独立前缀，测试清理不能碰业务前缀。SeaweedFS 的元数据后端使用 OceanBase 的 MySQL 兼容协议驱动，配置中 `[mysql]` 不代表部署 MySQL 服务。

备份格式为 4，拒绝旧格式。图片、视频保留原文件；正文、响应、市场数据采用对象压缩。导出文件生成时使用短期本地暂存，完成后发布为对象并删除暂存文件。API 鉴权后返回内容或短期 SigV4 下载链接。
