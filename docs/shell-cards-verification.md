# 侧栏、页脚与国家卡片验收

日期：2026-11-05。本地 Docker 前端、现有 API 与采集库，Chrome 实际页面。

## 改动

- 删除侧栏底部说明，按天枢侧栏样式加入双箭头折叠按钮。桌面展开224px（中屏190px），收起64px；按钮固定在菜单底部，菜单自身可滚动。折叠状态保存在本地浏览器，刷新后保持；图标仍有名称和悬停提示。手机横向导航及顶部导航不使用侧栏折叠。
- 页脚单独占据视口底部，正文在其上方滚动。原有说明和 API 链接保留，中间加入天枢页脚的公司版权、两个开源地址、微信和公众号文字。宽屏居中排布，窄屏自然换行；页脚不覆盖正文。参考内容来自天枢现有 `LayoutSidebar.vue`、`layout/index.vue`，未修改天枢仓库。
- 国家卡片改为应用总数、四色状态占比条及四项短标签数字。应用数与观察目标数不同时补充目标数；占比按观察目标计算。导入参考保留在应用矩阵和档案，不混入实测比例。卡片仍可点击下钻国家。

## 验证

| 项目 | 结果 |
|---|---|
| 1440×900，全部21个页面 | 页脚底边均为900px（浮点误差小于1px）；正文底边等于页脚顶边，无页面级横向溢出 |
| 1920×1080 分组看板 | 页脚底边1080px，正文底边1042.5px；版权区域在内容区水平居中；折叠按钮底边1080px |
| 折叠、刷新、展开 | 224→64→刷新仍64→展开224；导航名称和入口保留 |
| 390×844 | 分组、应用库、排行榜、关键词、采集、导出页脚均贴底；正文仍可滚动；国家卡片下钻泰国正常 |
| 29张国家卡片 | 实测高度164px，内容未超出卡片；每张色条各段之和为完整宽度 |
| 深色、顶部导航、居中定宽预览 | 页脚继续贴底，顶部模式隐藏侧栏折叠按钮；已取消预览恢复用户原设置 |
| 浏览器日志 | 未捕获 warning/error；数据采集错误仍按原业务数据展示 |
| 本地检查 | 64项前端测试通过，语法检查、生产构建、Docker镜像构建与Nginx配置检查通过 |
