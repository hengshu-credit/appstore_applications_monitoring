# 前端开发约定

本项目参考天枢决策引擎前端的配置和布局约定；具体技术架构为独立 Vite 前端 + Python API。未复制天枢页面或后端代码。

1. 一级菜单平铺。列表页和详情页复用基础表格、空态、错误态、日期、状态和按钮样式；操作必须有成功或失败反馈。
2. 筛选与页面操作同处一条响应式工具栏，筛选靠左、操作靠右；操作组紧凑排列，窄屏换行，不让整个页面横向溢出。宽表只在表格容器内滚动。
3. 所有矩形组件使用 `--radius: 0px`。包括按钮、输入框、标签、卡片、弹窗、抽屉、图片容器、提示和矩形图表，不使用胶囊控件。
4. 颜色从 `theme.css` 的语义变量读取；禁止在业务页固定浅色背景或文本颜色。普通图表使用主题衍生色，成功、警告、失败颜色不与普通分类配色混用。
5. 主题配置在 `theme.js` 规范化和校验；预览、取消还原、保存持久化的行为保持一致。新增配置要同时覆盖默认值、校验、UI 和测试。主题偏好与访问令牌分开处理。
6. 控件提供标签、键盘焦点和必要的 aria 属性；状态同时显示文字。主题切换必须检查表格、图表、空态、错误态、弹窗和禁用控件。色弱辅助不等于完整无障碍合规声明。
7. 前端仅访问 HTTP API；不在浏览器直连数据库、执行采集、保存 API 密钥或计算未定义的数据估算。
8. 新列表必须说明分页/返回上限，指标必须保留来源、市场、观察时间和覆盖范围。不同国家、语言、来源不可混为同口径排名。
9. 验证顺序：启动前后端，检查实际页面与窄屏；运行前端交互/主题测试和生产构建；运行后端实际 MySQL 测试；提交推送后核对最终 SHA 的全部远程 CI。

参考代码：天枢 `rule-engine-web/src/theme/themeConfig.js`、`themeRuntime.js`、`styles/theme-tokens.scss`、`components/theme/ThemeSettingsDrawer.vue`、`styles/index.scss`。天枢自身仍有圆角，本项目按用户明确要求统一直角。
