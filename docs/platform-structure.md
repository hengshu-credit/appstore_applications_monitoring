# 观星工作区结构

使用“找到应用 → 加入分组 → 按国家观察 → 下钻应用 → 处理事件或调整采集”的工作路径。

## 导航与职责

主导航保留 12 个平铺入口，不折叠隐藏功能；相关工具通过工作区页签切换。全部 21 个原有路由和权限键保持不变，入口自动指向用户有权访问的首个页面，页签不扩展授权。

| 分区 | 入口 | 页面与职责 |
|---|---|---|
| 监控 | 工作台 | 平台采集覆盖、运行情况与异常概览 |
| 监控 | 应用分组 | 按业务分类的一批 APP：跨国家看板、应用矩阵、权限、关键词与榜单、下载收入；应用档案内查看评分和变动 |
| 监控 | 市场上下架 | 当前市场状态快照、缺失复核与事件；分类关注名单跟随顶部商店和国家，包含全部请求语言 |
| 监控 | 事件与告警 | 事件记录、告警规则与日报 |
| 分析 | 应用库 | 发现、检索、筛选、查看档案、批量加入分组 |
| 分析 | 排行榜 | 全球排行榜、单市场榜单追踪、精品推荐 |
| 分析 | 关键词与 ASO | 关键词研究、应用文案草稿 |
| 分析 | 市场研究 | 少量竞品对比、开发者、市场分布、广告观察 |
| 分析 | 评论工作台 | 评论查询与处理记录 |
| 管理 | 采集中心 | 任务创建、周期、队列、日志、质量；详情监控任务保留为子页 |
| 管理 | 数据管理 | 数据导出、采集连接和授权配置 |
| 管理 | 账户管理 | 角色权限及个人设置 |

应用分组负责组合监控和汇总。竞品对比负责少量同市场应用的比较。采集中心负责执行配置，不承担业务看板职责。

## 筛选口径

- 页头说明当前工作区职责及范围。仅显示实际生效的商店、国家和语言控件。
- 分组使用看板内独立筛选，顶部商店和地区控件隐藏；选择国家后，国家分布与应用列表保持一致。
- 全球排行榜的国家范围在榜单内选择。概览、开发者、告警、广告、导出和详情监控任务按商店覆盖全部国家；隐藏无效的国家和语言控件。
- 采集中心列表按商店及本地列表条件筛选；顶部国家和语言用于新建任务默认值，明确说明用途。
- 分组“总览”只筛选商店、国家及期间；状态和名称搜索仅用于应用明细页。回到总览清除隐藏的列表条件。事件和经营指标始终按商店、国家及期间计算。
- 尚未验证、缺失待确认、已验证在架和地区不可用分别展示。新增关注、首次验证和恢复在架是不同事件，不混算为商店新上架。

## 组件边界

主侧栏和导航样式限定在 `.app-sidebar`、`#navigation`，不影响业务页的 `aside` 和 `nav`。多行可点击卡片使用 `.content-card`，不应用表单按钮固定高度。国家卡和分组卡按内容自然增高；宽表在自身容器滚动。

页面清单及范围统一在 `frontend/src/navigation.js` 维护；浏览器验收记录见 [UI 验收](ui-restructure-verification.md)。
