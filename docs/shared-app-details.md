# 公共应用明细

应用分组和其他页面共用 `app-detail-table.js` 的应用信息、状态监控、商店资料、通用榜单、应用自身分类榜单、权限、下载、收入、评分和关键词字段。应用库、榜单详情与历史、榜单追踪与增长发现、关键词搜索结果及应用覆盖榜、监控名单、开发者产品、竞品对照、地区矩阵、ASO文案和推荐关联应用均使用该组件；各页面自己的排名、增量、操作及分页保留。

`POST /api/apps/detail-rows` 为只读批量查询，最多200个明确的商店/应用/国家/语言目标，使用 `apps:read` 权限。它不新增应用、分组成员或采集任务。榜单位置、关键词和指标计算复用分组数据口径，但分组内的人工状态/权限修正仅在原分组生效。未知显示 `-`，有效样本未入榜留空，真实零值保留。普通页面默认展示当前市场近30天指标；历史列表的快照排名仍保留，当前明细不代表该历史时点。

全站普通表格的边框和底纹由 `table-surfaces.css` 统一；它不修改原表格字号、宽度、内边距和布局。明细表仍保留固定应用列及横向滚动。面包屑和页面标题使用一致字号。

榜单追踪在双商店视图提供两套官方分类选择器，Google Play 与 App Store 的分类ID分别保存。进入单店管理和新建采集计划时保留所选分类；仅支持总榜的来源不会伪装成分类榜。

原“精品推荐”改称“商店编辑推荐”：它保存 App Store Today 推荐故事、专题及关联应用的地区快照，用于回看编辑推荐曝光。页面卡片顺序不是下载或收入排名，Google Play 暂无对应采集来源。推荐故事下面提供关联应用的公共明细表。
