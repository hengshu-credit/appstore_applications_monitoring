# 应用明细统一视图

日期：2026-11-06。

分组只保留“分组总览”和“应用明细”。原应用矩阵、权限采集、关键词与榜单、下载与收入四个列表合并，每行显示同一 APP 在一个商店、国家和请求语言下的完整摘要，不把不同市场数据混在一起。

| 分区列 | 内容 |
|---|---|
| 应用 / 市场 | 应用名称、ID、商店、国旗、国家与语言；点击名称打开完整档案 |
| 上下架与监控 | 实测状态、任务状态、详情成功时间、独立的导入参考；采集错误可展开 |
| 权限采集 | 采集状态、声明项数、类别、成功时间、采集问题；完整类别可原位展开 |
| 关键词与榜单 | 分别显示有效样本命中数和最佳排名，0与没有有效样本保持区分 |
| 下载量 | 所选期间数据、实际/估算、覆盖天数；全球累计安装下限单独注明 |
| 商店收入 | 保留币种、实际/估算与覆盖天数，不合并不同口径 |
| 评分 | 最近公开评分及累计评分数 |

宽屏使用轻分隔线、主题状态标签和固定应用列；信息列上下分层。较窄桌面屏幕在表格内部横向滚动，应用名称保持可见。手机上同一条应用记录变为完整信息卡，指标按两列排布。分页、搜索、状态筛选和导入下载/收入仍在同一视图；支持本页全选并移出分组。历史曲线、逐项权限和评论等保留在应用档案内。
