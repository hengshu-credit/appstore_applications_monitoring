# 评论记录

2026-11-06：观星只收集、保存和查询应用商店评论，不承担评论处理或回复工作流。

- 导航入口改为“评论记录”。可按应用 ID、星级、版本、内容/标题和首次观察日期筛选，支持分页与“仅看此应用”。
- 记录展示应用、商店与市场、原文、星级、版本、发表时间、首次及最近观察时间。详情为只读，可查看最近100次采集历史；已采集的商店公开回复仍作为原始数据展示。
- “配置评论采集”带入当前应用并默认选择用户评论，仍需预览及创建计划，不会因查看页面而启动采集。
- 移除待处理/已处理状态、负责人、人工标签、处理备注、回复草稿及其筛选、保存入口。删除评论处理写入接口及新建处理记录导出的选项。
- 评论查询不再关联旧工作流表。`review_workflow` 表仅为既有数据和备份兼容保留，不删除历史内容；原评论表、采集任务和原始快照保留。
- `GET /api/research/reviews` 返回采集记录和同范围统计；`POST /api/research/reviews/history` 仍是只读查询，按商店、应用、国家、语言及评论 ID 隔离，使用 `reviews:read` 权限。

验证：69项前端测试通过。实际MySQL相关测试共31项，发现历史空结果类型不一致后统一返回列表，并复测3项评论归档/历史/统计测试通过，其余30项首轮通过。覆盖旧数据保留、处理接口404、已停用导出类型被拒绝、评论编辑历史、跨应用/市场隔离、多商店统计和HTML转义。语法检查、前后端镜像构建均通过。

浏览器实际验收了Google Play的100条记录、App Store的100条记录和双商店200条汇总；50条/店分页、应用筛选、只读详情及历史、带应用的评论采集配置均正常。详情没有输入框、选择框或回复操作。1920px及390px均未发现横向溢出；没有提交采集计划或写入评论处理信息。
