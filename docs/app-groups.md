# 应用分组看板

入口：一级菜单「应用分组」（`#groups`）。已有关注分类首次启动时自动建立分组，现金贷分类已对应 2,083 款应用、2,132 个国家/语言观察目标、29 个国家。同一应用可加入多个组，组内按商店、应用 ID、国家和语言去重。

## 管理一组应用

- 在应用库勾选 APP，点击「加入应用分组」，选择已有组或创建新组；支持同时选择两个商店。
- 在分组中使用「批量加入 APP」，每行填写 APP ID 或官方商店链接，指定默认商店和国家；跨市场名单支持 `store,app_id,country,language` CSV 行。
- 可编辑分组名称、说明，总览筛选商店、国家及期间；明细页另支持状态和名称筛选，返回总览自动清除这两个列表条件。成员列表分页访问完整数据。
- 移出分组只解除成员关系，保留其他组、采集任务与全部观察历史。已有任务的暂停状态、采集周期不会因加入另一组而重置。
- 「配置采集」可按当前国家/商店范围，启用并安排详情、Android 权限、三类总榜、近期评论和指定关键词。共享限速、冷却及全局暂停继续生效；已有任务的周期/深度保留，新任务默认24小时。任务数量不代表能在同一周期内全部完成。
- 「启停详情 / 权限」可暂停或恢复当前商店、国家范围的应用目标，包含列表搜索/状态筛选之外的成员；执行前显示具体范围。共享这些目标的其他分组也会受影响。暂停使在途租约失效，历史及上次有效数据保留；恢复不会清除尚未解决的错误。关键词、榜单、评论等市场共享任务在采集中心管理。

## 总览和应用档案

应用明细增加「类别」列，优先使用当前国家/语言的商店详情类别，缺失时使用已有应用类别，无记录时显示「未分类」。榜单列先展示全市场榜，再将同一商店、同一分类的免费榜、付费榜、畅销榜等排在一起；排序不受接口返回顺序影响，不合并不同商店的分类排名。

组级页面只保留“分组总览”和“应用明细”。应用矩阵、权限、关键词与榜单、下载收入已合并为同一列表，每行包含对应应用市场的全部摘要；下载收入导入也在此页。详细布局和验收见 [应用明细统一视图](unified-members.md)。

分组总览展示去重应用数、国家数、国家/语言目标数、最近有效状态、48小时新鲜度、异常数量和指标覆盖。国家卡可直接进入对应应用矩阵。组内统计采用独立筛选，顶部无效的市场控件隐藏。国家卡随所选国家过滤；尚未验证与缺失待确认分别计数，避免把采集积压视为下架异常。

新增关注目标、首次验证在架、重新出现、确认地区不可用分别统计。首次验证不等于商店新发布；初次未查到不等于已知应用下架；网络异常不会覆盖上次有效状态。事件按当前组成员回看，期间数量按应用×国家去重，日趋势逐日去重，不能把日趋势简单相加当作期间去重数。

导入名单中的参考状态单独显示，不写入观星实测状态，也不计入已验证在架/下架指标。参考更新时间保留原始文字，不猜测缺失的时区。名单再次导入时同步对应分类组和参考信息。

点击应用打开组内档案：

| 内容 | 展示 |
|---|---|
| 资料与状态 | 当前国家的资料、版本、开发者、评分及评分数、最近有效状态、导入参考 |
| 权限 | 商店声明的权限类别和逐项说明、成功时间、采集异常及最近30次尝试 |
| 关键词 / 榜单 | 当前或上次样本、是否过期、历史命中后本次未命中的词；点击可查看最近500次采样曲线；查看本市场导入参考报告、分页浏览和追踪所选词 |
| 下载 / 收入 / 评分 | 区域逐日指标、分币种/实际与估算曲线、评分变化，缺失值不补零 |
| 上下架与变动 | 事件时间线与字段变化；所选期间最近100条 |
| 评论 | 当前市场最近50条已采评论 |

关键词和榜单仅描述已配置目标的实际返回范围；未命中不等于下架。详情每类排名最多显示1000个目标，资料变更趋势最多300份快照。分组矩阵使用新鲜成功样本：有有效样本但没有命中显示0，没有有效样本显示缺失。

应用档案可直接切换该应用在组内的其他国家/语言目标，并单独安排详情/权限复核。导入报告与实测排名分栏展示，不把报告排名当作当前采样结果；报告按应用、商店、国家和语言校验绑定，禁止读取其他市场报告。所选报告词只在当前应用市场配置追踪。

## 权限采集

权限任务按 Google Play 应用×国家去重，与详情上下架状态独立，使用现有共享限流及租约。声明文本使用英文接口获取，已知类别提供中文标题，完整原文和原始响应保留。失败时保留上次成功清单；空的有效清单和未知结果区分处理。公开商店声明不代表设备实际授予的权限。

App Store 公开详情接口未提供同类声明权限清单，该列显示「公开接口未提供」，不会填入0或推测权限。权限 worker 随 `console daemon` 启动，持续处理已启用目标。

## 下载、收入与数据口径

支持通过分组导入 UTF-8 CSV：

```csv
store,app_id,country,date,downloads,revenue,currency,is_estimate
google,com.example.app,th,2026-11-01,0,12.50,THB,false
```

只允许本组已有应用及国家。日期必须是过去/当天，下载量为非负整数，revenue 表示商店付费下载、内购和订阅的净收入，需明确三字母币种，`is_estimate` 必填 true/false。缺失值留空，已知零值填写0。同一应用/国家/日期/指标/口径再次导入会更新该条事实，原有其他日期和指标保留。相同文件内冲突值拒绝整批导入。

授权市场采集器取得产品身份后，可把逐日分国家的下载/收入估算写入同一事实表。收入币种必须由响应提供，或由已确认的服务器私有连接配置 `currency` 指定；币种未知时收入只保留在原始归档，不擅自标为美元。实际和估算、不同币种分别汇总，不做汇率转换。累计安装下限仍按全球口径单独展示，不换算日下载。

## 存储和权限

新增 `app_groups`、`app_group_members`、`app_reference_states`、`app_permission_targets/runs`、`app_metric_facts` 和 `marketdata_product_links`。均纳入现有初始化、备份和测试隔离表注册表，不修改既有应用、关注任务或历史表结构。

组看板使用 `groups:read`，管理使用 `groups:write`；批量加入还需 `watchlist:write`，安排采集还需 `collection:write`。现有账号自定义授权不会被自动放宽，管理员可在账户管理中授权新模块。

所有浏览和聚合从已存观察读取。国家和币种隔离、零值/缺失、错误保留历史、跨组复用、分页、并发初始化及权限边界均有本地测试。
