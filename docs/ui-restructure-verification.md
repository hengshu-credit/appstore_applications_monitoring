# 平台结构与 UI 浏览器验收

日期：2026-11-05。环境：本地 Docker 前端、现有 API 与采集库，Chrome 已登录会话。

## 问题与修复

1. 原分组与国家卡被通用按钮规则固定为 42px，实际内容高于容器，文字跨行重叠。多行卡片独立使用自然高度；主侧栏样式改为组件作用域，分组侧栏不再继承导航文字和滚动条颜色。
2. 21 个页面原来全部并列，分组、竞品、任务和数据设置职责不清。现在按监控、分析、管理组织为 12 个入口，保留 21 个路由，相关页面通过工作区页签进入；原权限键不变。
3. 分组内独立筛选与顶部市场选择同时出现，形成双重口径。分组隐藏无效顶部控件；其他页面声明实际作用范围。市场上下架的分类关注名单统一跟随顶部商店和国家。
4. 尚未采集曾与疑似缺失合并为待复核。现在分开显示尚未验证、缺失待确认、已验证在架与地区不可用；回到总览清除仅适用于明细列表的名称和状态条件。
