# 账户、会员与权限

观星采用持久化账号密码登录，参考天枢的首次初始化与后续登录流程。升级后旧访问令牌不再用于登录，原有应用和监控数据保留。

## 首次启动与日常使用

1. 启动 API、前端和原有 MySQL。数据库初始化会幂等创建账户相关表。
2. 首次打开前端创建唯一超级管理员。数据库行锁保证并发请求只能创建一位超管；完成后初始化入口关闭。请在将新实例开放给外部用户之前完成此步骤。
3. 保存首次注册显示的恢复码，之后使用账号和密码登录。恢复码不在数据库中明文保存，页面关闭后无法再次查看。
4. 外部用户从登录页注册，固定为普通用户。超管可在“账户与权限”关闭或重新开启注册。
5. “我的账户”支持使用当前密码修改账号和密码，修改后所有旧会话失效，需要重新登录。
6. 忘记账号或密码时，在登录页使用恢复码设置新密码，系统显示原账号和新的恢复码。旧恢复码立即作废。普通用户也可联系超管重置账号密码；超管重置密码时生成新的恢复码供安全交付。超管通过个人设置或自己的恢复码恢复，不允许停用或降级唯一超管。

账号不区分大小写，允许 3–64 位字母、数字、下划线、点和短横线。密码长度 10–128 个字符。此版本使用恢复码，不发送邮件或短信；丢失超管密码及恢复码时需由数据库运维按组织的身份核验流程处理，没有公开的无凭据重置入口。

## 权限配置

权限按 18 个业务模块区分“查看”和“操作”，操作权限自动包含对应查看权限。前端按权限显示菜单、拦截页面，API 独立校验权限，包括直接访问 URL、修改请求和导出下载。通用商店目录、分类计数和图标供登录后的页面显示使用。

| 类型 | 默认权限 | 配置方式 |
| --- | --- | --- |
| 超级管理员 | 全部业务功能及账户权限管理 | 唯一初始化账户；不支持从外部注册或修改角色提升 |
| 普通用户 | 概览、应用库、榜单中心、全球排行榜、市场分布的查看 | 超管配置普通用户角色 |
| 会员 | 除采集中心外所有业务模块的查看 | 超管配置会员角色，并可给用户设置到期时间 |

会员到期后自动按普通用户角色计算权限，不依赖定时任务；空到期时间代表长期。超管可给任意普通用户或会员单独设置完整权限集合，或恢复继承角色默认权限。单独配置的用户权限优先于角色权限，会员到期后仍持续有效；希望会员权益随到期失效时，请使用角色继承。

角色默认权限修改对已有会话下一次请求生效；单用户变更、停用及密码重置撤销该用户现有会话。账号列表支持搜索、每页 100 条分页，安全操作记录展示最近 200 条。

通用采集管理和任务配置需要采集中心操作权限，关键词、重点监控等模块自己的任务控制需要对应模块的操作权限；应用详情一键采集和全球榜单采集计划还要求来源模块操作权限。榜单与推荐历史按目标真实类型授权，不能通过更改目标 ID 越权。应用详情包含该应用的排名、关键词和事件摘要，概览包含全站统计；本版本按页面功能授权，不按国家、商店、应用或创建人隔离数据。导出权限允许查看共享导出记录及下载导出数据，授予前请确认用户适合访问这些共享资源。

会员开通、延期、降级当前由超管手工管理，未接入支付、订单或自动续费。后续支付服务应在验证支付回调后由后端更新会员身份与到期时间，不能信任浏览器传入的会员状态。

## 部署与会话

- `APPMON_ALLOWED_HOSTS` 填实际前端域名（不含端口），保留所需的本地地址。
- HTTPS 部署（含反向代理终止 TLS）设置 `APPMON_COOKIE_SECURE=true`；本地 HTTP 开发使用 `false`。
- Cookie 为 HttpOnly、SameSite=Strict，8 小时到期；数据库只保存随机会话令牌的摘要，重启 API 不会主动清空有效会话。退出、停用、修改凭据均会撤销会话。
- 修改类请求校验会话绑定的 `X-CSRF-Token`，同时保留 Host、Origin、跨站来源和请求体大小检查。
- 密码使用随机盐 PBKDF2-HMAC-SHA256（600,000 次）保存；登录、注册、恢复及账密修改使用数据库限流，多个 API 实例共享计数。不要在不可信的反向代理头中传入客户端地址来绕过限流；当前同一代理后用户共享 IP 限额。
- API 客户端通过 `/api/auth/login` 登录，保存响应 Cookie，并把返回的 `csrf_token` 用于修改请求。`/api/auth/me` 可恢复当前会话和 CSRF 值。API 定义仅超管可访问。

测试覆盖真实 MySQL 的初始化竞争、注册角色不可提权、旧令牌不可绕过、CSRF、直接 API 越权、会员到期、角色与个人权限、停用、恢复码轮换、凭据修改、会话过期以及共享限流。前端测试覆盖初始化、恢复码保存确认、登录、菜单过滤、个人修改和会员权限编辑。
