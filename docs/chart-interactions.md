# 观星公共图表

应用档案、应用分组、关键词与榜单趋势、评论与事件统计共用 `monitoring-charts.js` 和 `monitoring.css`。数据图与采集血缘流程图分别保留各自的用途和操作。

- 图线随容器宽度变化，普通数据点固定5px，激活点7px；轴标签和提示文字独立于SVG缩放。手机自动减少横轴标签，不要求横向滚动。
- 横轴按实际观察间隔定位，按跨度显示日期或日期加时分；秒级精确时间放在提示中。单一时间只显示一个标签。评分使用0–5刻度，排名越靠前位置越高。
- 提示浮层展示格式化数值、观察时间和来源备注；数值四舍五入时保留原始值供核对。缺失值不补零、不跨缺失点连线；无有效值和无历史记录分别显示空态。
- 悬停或键盘聚焦查看，点击/触摸或回车/空格固定，再次点击取消固定。Esc、关闭按钮或点击外部可关闭；滚动、窗口变化和页面移除也会清理提示。
- 每图一个Tab入口，方向键逐点浏览，Home/End跳到首尾。弹窗中的提示留在弹窗层级，Esc优先关闭图表提示。折线和条形图共用这些操作，提示随明暗主题变化。

验证覆盖真实零值、缺失断线、重复时间、评分精度、输入转义、固定与关闭、键盘导航、弹窗层级、卸载清理，以及390/1440/2560宽度的浏览器布局。
