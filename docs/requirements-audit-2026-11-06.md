# 观星需求复核（2026-11-06）

本次按历史需求检查当前代码、本地数据与浏览器页面。结论：界面及共享组件已有主要实现，但此前确有遗漏；本次补齐了旧查询表单和详情监控分页。第三方试用数据的尽量完整采集仍未完成，不能以授权成功或页面已上线代替数据验收。

## 仍需明确的限制

- 授权数据源的真实批量结果尚未取得。当前令牌对榜单资源仍返回无权限，下载 / 收入尚无事实记录；不能声明“试用采集完成”。
- 原始资料不存在的应用、来源不公开的权限或经营指标仍为空。已采字段保存更丰富，与全部应用全部字段已采到是两回事。
- 应用库为了避免对大池反复计数，页码模式没有全量总页数；部分列表固定页长。旧精品推荐目标列表仍保留 2,000 条上限，部分详情的历史列表有 100 条上限；平台全部历史列表的无损分页仍有后续范围。
- 浏览器覆盖了 21 个导航页面 / 子页及关键词内嵌页面；重点交互验证公共筛选、重置、Enter、详情监控翻页、分组明细与弹窗。未逐条点击全部数据记录，也未把无数据的页面当作采集成功。
